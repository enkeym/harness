# hooks-guards

Harness installs no global lifecycle handlers. For a refusal, distinguish native sandbox/approval policy from a project's `.codex/hooks.json` or inline hooks. Inspect only the relevant configuration and handler; check current official hook documentation before changing its protocol. Keep native sandbox and approvals active; never retry a denied action through another tool. Request native escalation only when supported and required. A previous user authorization remains valid within its scope. Do not promise a confirmation dialog from a hook.
