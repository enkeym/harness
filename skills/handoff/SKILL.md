# handoff

When requested, record the objective, constraints, decisions, completed changes, test results and next concrete step in a compact project note. Include branch, affected paths and log locations, not copied source or full logs. Carry existing authorization and unresolved questions forward. Finish at a coherent work boundary; do not restart sessions automatically or invent context thresholds. Use Codex resume to continue an existing session. Do not assume a transcript format or switch models. Never create a new task unless requested.

Rebuild the note from current state, aiming for at most 3000 characters; replace
the previous snapshot instead of appending. Keep only decisions, affected
contracts and verification the remaining work needs. Use exact paths/symbols,
absolute dates and the next executable action. Read the named ranges on resume;
do not reload all files or rerun unchanged successful checks. For native
compaction, preserve the same essentials in the summary and continue the task.
