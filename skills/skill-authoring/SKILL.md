# skill-authoring

Keep SKILL.md focused on decisions that Codex cannot infer. Use name and description frontmatter; scope the description to actual triggers. Store substantial conditional guidance in linked reference files. Reuse existing skills and shared rules. Global sources live in skills/ and are linked into ~/.agents/skills. Project skills live under .agents/skills. Validate names, links and commands; do not invent tools or force model changes.
