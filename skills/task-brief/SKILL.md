# task-brief

Inspect affected code through tokensave-routing: scoped search and small lines ranges; use context without code only to locate unfamiliar structure. Reuse project decisions. State the goal, boundaries, assumptions, implementation steps and verification. Ask only about unresolved choices that materially affect the result. Existing user authorization is sufficient to proceed; do not introduce an additional approval gate. For a design choice, compare the strongest alternatives with evidence.
