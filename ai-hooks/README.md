# Инструменты harness

Здесь запуск MCP (`bin/mcp-serve.sh`), создание и проверка карты связей,
ручные задачи индексации (`project-init.sh`, `ragsave-sync.sh`).
Первичную индексацию запускают только по решению пользователя.
SessionStart/Stop запускают фоновое обновление существующего RAG-индекса.
PreToolUse запускает mcp-search-guard.mjs: штатный hook TokenSave распознаёт
поисковые вызовы, адаптер возвращает Codex deny с подсказкой tokensave/rag_search.
Regex и запросы вне индекса сохраняют штатные исключения TokenSave; это помощь
в выборе инструмента, а не граница безопасности. Сбой бинаря явно предупреждает
через systemMessage. Hook не исполняет проверяемую команду и не даёт разрешений.
Определения из codex/hooks.json нужно доверить через /hooks; разрешения и sandbox обеспечивает Codex.
Проектные hooks настраиваются отдельно в `.codex/hooks.json` репозитория.

Проверка: node --test --test-concurrency=1 ai-hooks/test/test-*.mjs.

Шумная неинтерактивная команда: `bash ~/.ai-hooks/bin/brief-output.sh npm test`.
При успехе выводятся последние 20 строк, при ошибке — первые 20 и последние 60.
Полный stdout/stderr остаётся в приватном файле временного каталога; путь,
размер и исходный код завершения печатаются в конце. Лог удаляется вручную,
когда больше не нужен. Аргументы передаются напрямую, shell-строки не принимаются.
Интерактивные команды и полные diff для review запускаются обычным способом.
Скрипт не подключён к hooks и не меняет native approvals.
