| Практика основной ветки | Подключение в Codex |
| --- | --- |
| Обязательный MCP для индексированных файлов | scoped search/files → read с небольшими ranges; RAG для смысловых вопросов; shell fallback только при названном ограничении |
| Поиск без блокировок | MCP задаётся инструкциями; PreToolUse не подключается, лишних отказов и повторов нет |

| Меньше лишних запросов | Независимые чтения/поиски объединяются; результаты и успешные проверки переиспользуются до изменения входов |

| Сохранение рабочего контекста | Нативная компакция Codex; summary хранит цель, ограничения, решения, проверки и следующий шаг |
| Контроль расходов | /optimize измеряет объём вывода, повторы и число вызовов; токены и деньги — только по поддерживаемым данным |

Обязательный шаг активации автоматики: в Codex открыть `/hooks`, проверить и
доверить новые определения SessionStart/Stop. Изменение hooks.json сбрасывает доверие
к изменённым определениям. В текущей установке файл уже связан с репозиторием.
`./install.sh --check` подтверждает установку, но не подтверждает доверие.
Чтение индексированных файлов через MCP закреплено в codex/AGENTS.md и rules/core.md.
Каталог инструментов фильтруется до нужной схемы; полные описания серверов не выводятся.
Нужные тесты запускаются без вопросов; успешные проверки не повторяются без изменения входов.
Источник: [официальные hooks Codex](https://learn.chatgpt.com/docs/hooks).

Переменная FORCE_PROMPT_CACHING_5M, парсеры транскриптов Claude, фиксированные
пороги 100k/150k/220k и принудительная смена моделей не переносятся. Инструкции
предписывают переиспользовать схемы и стабильные правила; это не гарантирует cache hit.
Codex поддерживает model_auto_compact_token_limit, но harness сохраняет модельные
значения по умолчанию до измерений на реальных задачах.
Источник: [конфигурация Codex](https://learn.chatgpt.com/docs/config-file/config-reference).

Измерение brief-output.sh: сравниваются байты полного лога и байты короткого
вывода на одинаковом синтетическом запуске. Это сокращение вывода инструмента,
а не оценка оплаченных токенов. Полные diff, security audit и интерактивные
команды не обрезаются. При ошибке читаются нужные участки сохранённого лога.

`tokensave cost today --by-agent --export json` доступен для проверки ledger.
Нулевые счётчики или модель `<synthetic>` не доказывают расход Codex: по ним
нельзя вычислять стоимость текущей сессии или cache hit rate.
