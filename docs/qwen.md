# Qwen Code

Установить общие навыки, инструкции, MCP и фоновые RAG hooks:

```sh
./install.sh --qwen
./install.sh --qwen --check
qwen mcp list
```

По умолчанию используется `~/.qwen`; `QWEN_HOME` задаёт другой каталог.
Установщик восстанавливает отсутствующие и битые ссылки на навыки, подключает
`qwen/QWEN.md`, сохраняет заменяемые файлы и ссылки с суффиксом `.bak-<timestamp>`.
Пользовательские настройки модели, авторизации, MCP-серверы и hooks сохраняются.
Серверы harness синхронизируются из `mcp/servers.json`.
Для серверов через catalog proxy используется прямой запуск backend: Qwen
запрашивает prompts/resources при обнаружении и не сохраняет ленивый запуск.

Для RAG нужны установленные tokensave и ragsave; подготовка Python окружения:
`./install.sh --codex --venv`. Индексы создаются вручную в нужном проекте.
MCP выбирает проект из `QWEN_PROJECT_DIR`, затем `CODEX_PROJECT_DIR`, затем cwd.
SessionStart/Stop обновляют только существующие индексы; timeout hooks — 10000 мс.
`--check` не изменяет файлы и не доказывает исполнение hooks или доступность модели.
Запускайте Qwen в каталоге проекта. Изменения настроек применяются в новой сессии.
