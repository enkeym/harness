# OpenCode в harness: состояние на 1 ноября 2026

Цель: подключить OpenCode к общим правилам, навыкам и инструментам Codex/Qwen. Ветка: `codex`. Изменения пока не закоммичены и не отправлены.

## Сделано

- Добавлен установщик `bin/opencode-install.mjs`, запуск: `./install.sh --opencode`; проверка без записи: `./install.sh --opencode --check`.
- В `opencode/` сохранены базовый конфиг, инструкции и плагин. Общие правила `rules/core.md` подключены через нативный `instructions`, установлены ссылки на навыки.
- `bin/mcp-sync.mjs --opencode` подключает TokenSave, RAGSave и Playwright из общего `mcp/servers.json`. Пользовательские настройки сохраняются, перед записью создаются резервные копии.
- Плагин использует `context.location.directory`. При загрузке запускает синхронизацию существующих индексов и прогрев RAG; после событий завершения, ошибки или прерывания ответа повторяет синхронизацию. Подписка V2 читается как асинхронный поток.
- Локально продублированы подключения Qwen: `qwen-deepseek` и `qwen-apimira`, четыре модели. По умолчанию выбран `qwen-deepseek/deepseek-v4-pro`. Оба провайдера ответили на проверочные запросы.
- Ключи хранятся вне Git в `~/.config/opencode/keys/`, права 600; конфиг ссылается на них через `{file:...}`. Фоновый сервис перезапущен.
- Добавлены тест сохранения настроек MCP и документация `docs/opencode.md`.
- Общий модуль `opencode/config.mjs` поддерживает JSONC и рекурсивное объединение `opencode.json` с `opencode.jsonc`, сохраняет комментарии и резервные копии. JSONC имеет приоритет.
- Добавлен явный импорт OpenAI-совместимых провайдеров Qwen: `./install.sh --opencode --import-qwen`. Ключи берутся из окружения по `envKey` и сохраняются в приватных файлах вне Git. Обычная установка ключи не копирует; `--check` не пишет файлы.
