# Codex harness

Read `~/.config/harness/repo/rules/core.md` before the first task.
Before each task and when its scope changes, select only skills whose scope the task actually touches from `~/.agents/skills` as required by core.md; read only missing or changed SKILL.md instructions, reuse unchanged contents still in context and restore missing instructions after compaction or session transfer.
Use MCP to search/read indexed project files; shell fallback requires a stated index/tool limitation. Without an index, use local tools and do not load tokensave-routing.
Project AGENTS.md decides project conventions; only an explicit user request can lift core.md's ban on adding or rewriting code comments, including JSDoc.
Perform edits and focused checks autonomously; follow core.md confirmation rules for sensitive operations and reuse explicit user authorization.
Use the installed tools.
